# RAG Agent

A minimal but precise Retrieval-Augmented Generation (RAG) agent built from scratch in Python, powered by Claude (Anthropic).

## Features

- Multi-source ingestion (PDF, Markdown, Web)
- Custom chunking & embedding pipeline
- Cosine similarity vector search (no framework)
- Claude-powered answer generation

## Stack

- Python 3.11+
- Anthropic Claude API
- sentence-transformers (embeddings)
- numpy (vector search)
